# Ali İhsan Alpargu

I'm a third-year Computer Engineering student at Yıldız Technical University, interested in AI and software that solves problems I run into myself. I'm currently looking for an internship.

Most of my recent projects started as tools I wanted to use: reading and organizing books, spending less time on distracting apps, planning work, or keeping a searchable archive.
